# PrettySites Web Builder

**A free web design skill for Claude, Codex and Cursor**

Give your AI builder a clear brief, deliberate typography and one memorable motion idea. The skill guides the work from a written spec to editable frontend code and visual review when browser tools are available.

## Install

### Claude Code

Run these commands inside Claude Code:

```text
/plugin marketplace add prettysites/web-builder
/plugin install prettysites-web-builder@prettysites
```

### Claude desktop and Claude.ai

1. [Download the ZIP](https://github.com/prettysites/web-builder/releases/latest/download/prettysites-web-builder.zip).
2. Open **Customize → Skills**, choose **Upload a skill**, and select the ZIP.
3. Enable the skill. Code execution and file creation must be enabled in Claude.

### Codex and Cursor

[Download the ZIP](https://github.com/prettysites/web-builder/releases/latest/download/prettysites-web-builder.zip) and extract the `prettysites-web-builder` folder — the folder containing `SKILL.md` — to:

| Agent | All projects | This project only |
| --- | --- | --- |
| Codex | `~/.agents/skills/` | `.agents/skills/` |
| Cursor | `~/.cursor/skills/` | `.cursor/skills/` |
| Claude Code, manual install | `~/.claude/skills/` | `.claude/skills/` |

If you clone the repository, the skill folder is `plugins/prettysites-web-builder/skills/prettysites-web-builder`. Copy that whole folder, including references and scripts. Open a new chat or restart the agent if the skill does not appear.

## Try a brief

After installing, paste this into your agent:

```text
Use PrettySites Web Builder to create a responsive landing-page hero
for a fictional ceramic studio called Forma.

Warm ivory, deep brown and one terracotta accent. Large, readable type.
One memorable motion idea; keep the controls and supporting copy quiet.
Use my project's existing stack, or a standalone index.html for a new project.

Write the design spec, build the page, then inspect desktop and mobile
screenshots with the available approved tools. Fix visible issues and
explain anything you could not verify. Do not invent testimonials or metrics.
```

In Codex, you can explicitly invoke `$prettysites-web-builder`. In Claude Code, the plugin skill is `/prettysites-web-builder:prettysites-web-builder`.

You can also ask for a **prompt only** for another builder. The skill includes guidance for Lovable, Bolt, v0, Claude Code, Codex, Cursor and Kimi.

## What the skill includes

- **A concrete design spec** — type, colours, spacing, copy, breakpoints and motion timings.
- **68 motion recipes with example code** — glass, text reveals, depth carousels, Three.js, scroll-driven media and more. These are examples to adapt and check, not a tested component library.
- **Media guidance** — image/video prompt formulas, posters, MP4 preparation and mobile framing.
- **Visual review** — desktop, phone and first-paint checks with an approved browser tool or the included Node/Python helpers.
- **Builder prompts** — a detailed brief when you want a prompt instead of code.

Bring your own assets, use an available generation tool, or choose a typography-led design.

<details>
<summary>Optional screenshot helper setup</summary>

Use the host's approved browser tools when available. Only run local browser automation where your environment permits it.

For the Node helper, install Playwright inside the extracted skill folder so the script can resolve it:

```sh
cd /path/to/prettysites-web-builder
npm install --no-save --package-lock=false playwright
npx playwright install chromium
node scripts/qa.mjs http://localhost:5173 shots/
```

For the Python helper:

```sh
python -m pip install playwright
python -m playwright install chromium
python /path/to/prettysites-web-builder/scripts/shoot.py http://localhost:5173 shots/
```

Replace the skill path and local URL with your own. Open the resulting screenshots; automatic checks do not replace visual inspection.
